# Robotics Challenge 2026 — 로봇 코드

2026 로보틱스 챌린지(문제해결 트랙, 주제: Health Emergencies) 참가 로봇 코드입니다.
LEGO SPIKE Prime + [Pybricks](https://pybricks.com/) (MicroPython) 기반.

## 파일 구성

| 파일 | 설명 |
|---|---|
| `A_main_y2.py` | A 로봇 메인 실행 코드 |
| `A_test.py` | **[TEST]** A 로봇 모터 값 측정·동작 테스트용 |
| `B_main.py` | B 로봇 메인 실행 코드 |
| `B_main_new.py` | B 로봇 메인 실행 코드 (개선판) |
| `B_test.py` | **[TEST]** B 로봇 그립 모터 각도 측정·캘리브레이션용 |
| `C_main.py` | C 로봇 메인 실행 코드 |
| `C_test.py` | **[TEST]** C 로봇 모터 각도·바퀴 지름 측정·캘리브레이션용 |

> `*_test.py` 파일은 대회 본 실행이 아니라, 모터 각도·바퀴 지름 등 하드웨어 값을
> 측정·보정하기 위한 도구입니다. (각 파일 첫 줄 주석에도 명시)
